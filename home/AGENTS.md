# Commits and pull requests

Follow Conventional Commits 1.0.0 (https://www.conventionalcommits.org/en/v1.0.0/) for every commit message and PR title: `<type>[(scope)][!]: <description>`.

Types: `feat`, `fix`, `docs`, `style`, `refactor`, `perf`, `test`, `build`, `ci`, `chore`, `revert`.

Never use `--no-verify` to get past the `commit-msg` hook. Fix the message instead.
